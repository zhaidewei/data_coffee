# 前端模块边界

读者：维护网页的开发者与 PR 评审者。本文用于定位改动入口和核对兼容性。

`app/web/app.js` 负责共享状态、页面路由、活动加载、轮询刷新、滚动恢复和启动。页面继续使用原生 ES modules，由浏览器直接加载。

| 模块（`app/web/ui/`） | 职责 |
| --- | --- |
| `api.js` | 请求方法、幂等键与错误说明 |
| `dom.js` / `labels.js` / `display.js` | DOM 小组件、展示名称、时间与链接格式 |
| `sharing.js` | 分享卡片、复制、下载 |
| `tag-picker.js` / `event-widgets.js` | 标签、日期时段、人数与条件组件 |
| `account.js` | 登录、个人资料、Token 与账户菜单 |
| `home.js` | 总览、筛选、地图、卡片与介绍 |
| `event-detail.js` | 活动流程图、节点对话框与活动动作表单 |
| `event-form.js` | 新建和编辑草稿 |
| `assistant.js` | 助手会话、确认卡与失效提示 |

页面模块通过 `create…({state, …callbacks})` 接收入口拥有的状态与跨页面动作。回调闭包允许详情和编辑页互相切换，无需循环导入。入口只创建一次这些模块；账户和助手事件在创建时注册。通用模块没有启动副作用。

这次提取保留原函数正文、文案、DOM 和 CSS class；后端、路由和数据规则保持现状。新增测试覆盖 API 幂等键及错误说明、截止边界与荷兰时间展示。浏览器检查覆盖首页、开发登录、`#new` 模板创建及编辑、`#event` 节点对话框、`#cli` 文档。
