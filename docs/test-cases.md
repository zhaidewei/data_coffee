# MVP 测试清单

读者：开发者和产品验收者。实现前定义，结果以后续实际测试输出为准。

| 编号 | 场景 | 预期 |
|---|---|---|
| T01 | 发布完整草稿 / 不完整或错误时间草稿 | 正确发布并锁规则 / 拒绝 |
| T02 | 截止条件全部满足 / 任一缺失 | confirmed / cancelled，回执含逐项原因 |
| T03 | 多人同时抢最后一位 / 重复点击 | 无超额，一人一位，剩余按候补，无重复副作用 |
| T04 | 退出释放位置 | 队首自动递补，入选通知，人数足够不启动异常 |
| T05 | 递补后仍不足，逐次报名 | 开倒计时；不足不延长，恢复原最低人数才解除 |
| T06 | 场地撤回并提供未审核/已审核替代 | 未审核不能解除；符合容量及时段才解除 |
| T07 | 多个缺口并存 | 修复一项不消除另一项，到期仍缺失取消 |
| T08 | 晚执行Cron且同时收到截止后的变更 | 截止状态先计算，晚变更不改原回执 |
| T09 | 角色申请批准/退出/撤销，跨活动越权 | 按身份执行，权限即时收回；历史保留 |
| T10 | 访客、候补、正式报名、管理者查看私有地址/邮箱 | 仅授权角色见地址，公共接口无邮箱 |
| T11 | OTP错误、过期、重复、并发验证、限流 | 不登录/仅一次成功，不能重放或遍历 |
| T12 | 非loopback部署无Brevo密钥 | 不泄露开发码，明确报服务未配置 |
| T13 | AI伪造动作或身份、未确认、旧版本确认 | 不写入；正常join/leave卡确认才执行 |
| T14 | 邮件失败、重试、并发处理、日额度 | 持久状态可查，认领互斥，受控重试 |
| T15 | 手机端创建、参与、审核、候补与退出 | 真实API闭环、键盘可用、错误可理解 |
| T16 | 阿姆斯特丹10月夏令时边界 | 正确UTC转换，歧义明确处理 |
| T17 | 取消和完成终态 | 不能报名或因重试恢复 |
| T18 | Free资源预算 | 测试批处理时限；未实际部署不声称CPU配额已达标 |
